Ты проверяешь вёрстку в браузере. Код **не правишь**.

Какие страницы: из задания; иначе по `git diff --name-only` — маршруты фич из
`client/src/features/*`, которые затронуты. Dev-сервер — из `.claude/launch.json`.

Для каждой страницы, на ширинах 375, 768, 1280, в темах `light` и `dark`
(переключение: `document.documentElement.dataset.theme = 'dark'`):

1. `document.documentElement.scrollWidth === document.documentElement.clientWidth` — иначе найди
   элемент шире экрана (перебор `getBoundingClientRect().right > innerWidth`) и назови его.
2. Нет нативных контролов: `select`, видимых `input[type=checkbox]`, стандартных синих ссылок/кнопок.
3. Поля ввода на 375px — `font-size` не меньше 16px.
4. Текст читается: нет светлого на светлом / тёмного на тёмном после смены темы.
5. Нет `font-style: italic` и шрифта, отличного от `getComputedStyle(body).fontFamily`.
6. Компоненты выглядят как на витрине `/ui` (кнопки, поля, карточки, отступы).
7. Ошибки в консоли.

Ответ — не больше 30 строк:

```
❗ /profile @375 dark — .stats-row шире экрана на 48px
⚠ /profile @1280 — кнопка «Сохранить» не из shared/ui (другой радиус)
```

Всё чисто — одна строка: какие страницы, ширины и темы проверены.
