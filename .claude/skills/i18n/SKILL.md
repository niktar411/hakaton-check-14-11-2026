---
name: i18n
description: Добавить или изменить строки интерфейса через Paraglide — ключ в русском словаре, синхронизация словарей, перевод. Использовать при любом новом тексте в UI.
---

1. **Ключ** — в `client/messages/ru.json`, camelCase по месту: `profileTitle`, `jobsEmptyHint`,
   `saveFailed`. Русский текст — финальный, не заглушка.
2. **Параметры** — плейсхолдерами `{name}`, не склейкой строк. Склонения (`1 вакансия / 5 вакансий`)
   — через вариант сообщения Paraglide, не самописный `plural`.
3. **В коде** — `m.profileTitle()`; в списках уровня модуля — функция: `label: () => m.x()`.
4. `bun run i18n:sync` — допишет ключ во все словари русской заглушкой.
5. **Английский перевести сразу**; остальные языки — субагент **translator**.
6. Ошибки сервера приходят кодом (`job.not_found`) — у каждого кода есть ключ в словаре.
7. Удалил ключ из `ru.json` — удали и из остальных словарей.
