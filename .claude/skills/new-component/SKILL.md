---
name: new-component
description: Добавить новый UI-компонент в shared/ui (проверка на дубль, генератор, токены, состояния, доступность, витрина /ui). Использовать, когда нужного контрола или блока ещё нет.
---

1. **Сначала поищи готовый:** `client/src/shared/ui/` и витрина `/ui`. Похожий есть — добавь
   ему вариант или проп, новый не создавай (`Button2`, `CustomSelect` блокирует хук).
2. **Скелет генератором:**
   ```bash
   bun run new:component <ИмяPascal> [--dir client/src/features/<домен>]
   ```
   По умолчанию — в `client/src/shared/ui/`. Компонент одной фичи — в её папку.
3. **Оформление** — классы темы и `Имя.module.css`, значения только из токенов. Варианты
   (`variant`, `size`) — пропами, не отдельными компонентами.
4. **Все состояния:** hover, `:focus-visible`, disabled (с причиной в `title`/`aria-describedby`),
   loading, ошибка, если применимо. Всплывающая поверхность — `data-elevated`.
5. **Доступность:** клавиатура (Tab, Enter/Space, Esc, стрелки для списков), роли и `aria-*`,
   подпись у интерактивного элемента без текста.
6. **Solid:** props без деструктуризации, `splitProps` для проброса остального.
7. **Витрина:** добавь компонент во всех вариантах на страницу `/ui`.
