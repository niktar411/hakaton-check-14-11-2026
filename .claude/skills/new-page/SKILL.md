---
name: new-page
description: Добавить новую страницу или экран клиента (генератор, маршрут, i18n, четыре состояния, мобильная вёрстка, проверка в браузере). Использовать при создании нового экрана или раздела.
---

1. **Скелет — генератором**, не руками:
   ```bash
   bun run new:page <домен> --title "<Заголовок по-русски>" [--path /url] [--name ИмяPascal]
   ```
   Он создаёт `client/src/features/<домен>/<Имя>Page.tsx` + `.module.css`, ключ заголовка в
   словаре и маршрут в `App.tsx` (если там есть метка `@new-page`). Что не смог — напечатает,
   доделай по списку.
2. **Данные** — `createResource`/`query` через api-клиент `@/shared/api`. Эндпоинта нет — сначала
   навык `/new-route`, потом `bun run gen:api`.
3. **Четыре состояния:** скелетон при загрузке, пустое состояние с действием, ошибка через
   `useToast`, данные.
4. **Только готовые компоненты** из `@/shared/ui`; чего нет — `/new-component`.
5. **Тексты** — новые ключи в словарь, `bun run i18n:sync`, английский сразу переводом.
6. **Адаптив:** mobile-first, на телефоне — шапка «‹ Заголовок», основное действие во всю ширину.
7. **Публичная страница** (видна без входа): добавить в список пререндера, `sitemap`, `robots`,
   `client/public/llms.txt` и regex SSI в обоих конфигах nginx.
8. **Проверка:** открой страницу в браузере (dev-сервер из `.claude/launch.json`) или запусти
   субагента **ui-auditor** — 375/768/1280, обе темы, `scrollWidth === clientWidth`.

Готово, когда выполнен Definition of Done из CLAUDE.md.
