# OpenCode workspace instructions

- Do not ask clarifying questions unless an action is destructive and cannot be undone.
- Inspect the repository and make reasonable assumptions instead of asking the user to restate the task.
- For a normal task: find the relevant files, make the change, run the relevant checks, and report the result.
- Keep the final answer short: what changed, how it was checked, and any real limitation.
- This workspace is a clone. Do not try to push to the production repository or deploy from here.
