# Хуки проверки готовности

## guard

Защищает SQL-миграции, присутствующие в текущем HEAD. Новые миграции можно
редактировать после git add. Наличие в HEAD — политика неизменяемости, а не
свидетельство применения миграции в БД. При недоступном Git правка миграции запрещается.
Сгенерированные файлы защищены от Edit/Write; запрещаются распознаваемые команды
других менеджеров пакетов, force-push и обхода Git-хуков.
Это предохранитель: анализ команд регулярными выражениями не является изоляцией
исполнения и не покрывает произвольные скрипты, вложенные оболочки и все способы записи.

## done-gate и typecheck

Ошибки дают модели до трёх попыток исправления. Если ошибка сохраняется, следующий
Stop выдаёт continue:false, stopReason и явное сообщение «ПРОВЕРКА НЕ ПРОЙДЕНА».
Это остановка для человека, а не успешная приёмка. Новый пользовательский ход
сбрасывает бюджет попыток через stop_hook_active:false. Успешная проверка сбрасывает
свой счётчик. Состояние разделено по корню проекта, идентификатору сессии и имени хука.

Сбой Git или сканирования не считается отсутствием замечаний. Пути изменений
читаются с NUL-разделителями; переименование затрагивает обе области кода.
Typecheck учитывает исходники, конфигурацию TypeScript и зависимости.
Если затронут сервер, отсутствие Go или go.mod считается невыполненной проверкой.
Команды проверки ограничены 30 секундами каждая; таймаут — ошибка, не успех.
Typecheck проверяет типы и Go build/vet, но не заменяет запуск тестов и сборку клиента.

## Проверка

scripts/hooks.test.ts запускает настоящие программы хуков с JSON на stdin в
одноразовых Git-репозиториях. Проверки охватывают новые/staged/зафиксированные
миграции, защиту генерации, опасные команды, ошибки Git, кириллицу и пробелы в путях,
лимит попыток, отсутствие Go, конфигурационные изменения и переименование файлов.
Полный прогон: bun run check. Требуются права на создание временного Git-репозитория.
Фактическая загрузка настроек и события внутри Claude Code проверяются отдельно.

Формат вывода: https://code.claude.com/docs/en/hooks
