# SAM: дашборд и комплаенс-экран

Экран собирает KPI, риски и баланс лицензий из комплаенс-движка. Сервер сам
считает суммы, проценты и стоимости; клиент только форматирует и фильтрует
полученные строки.

## Схема

Миграция `server/migrations/00005_add_sam_compliance.sql` расширяет уже
существующие таблицы SAM, не создавая вторую параллельную модель:

- `sam_products.status` — `active`, `inactive`, `archived`, `banned`;
- `sam_licenses.cost_per_seat` — годовая цена места в рублях;
- `sam_licenses.currency` — пока только `RUB`.

Установка лицензии считается по уникальному `sam_installations.asset_id`.
Несколько версий одного продукта на одном хосте занимают одно место.

## Формулы

Для каждого продукта:

- `purchasedSeats` — сумма мест во всех лицензиях;
- `licensedSeats` — места лицензий без срока или со сроком не раньше сегодня;
- `expiredSeats` — места лицензий с истёкшим сроком;
- `installedDevices` — уникальные хосты с установленным продуктом;
- `overusedSeats = max(installedDevices - licensedSeats, 0)`;
- `idleSeats = max(licensedSeats - installedDevices, 0)`;
- `deltaSeats = installedDevices - licensedSeats`;
- `riskCost = (overusedSeats + expiredSeats + idleSeats) * avgCostPerSeat`.

Для запрещённого продукта баланс мест не считается: `licensedSeats`,
`expiredSeats`, `overusedSeats` и `idleSeats` равны нулю, а `deltaSeats`
показывает число хостов с запрещённым ПО. Так юридический риск не смешивается
с финансовым.

Итог:

- `costAtRisk = overuseCost + expiredCost` — деньги под прямым риском;
- `idleCost` показывается отдельно как замороженные деньги;
- `compliancePercent` — доля продуктов без превышения, просрочки, запрещённых
  установок и установок неактивных/архивных продуктов;
- `riskLevel`: `high` при превышении, просрочке или запрещённых установках;
  `medium` при простое или несопоставленных установках; иначе `low`.

## API

Маршруты ниже публичные и только для чтения. Те же ответы доступны под
`/api/sam/compliance/...` после входа участника (для внутренних экранов).

| Метод | Путь | Ответ |
|---|---|---|
| GET | `/api/public/sam/compliance/summary` | KPI, стоимость риска, рекомендации, разрезы по статусам и категориям |
| GET | `/api/public/sam/compliance/products` | баланс и риск по каждому продукту |
| GET | `/api/public/sam/compliance/risks` | риски, отсортированные по важности и стоимости |
| GET | `/api/public/sam/compliance/products/{id}` | продукт, его лицензии и затронутые хосты |
| GET | `/api/public/sam/compliance/hosts/{id}` | хост, установленное ПО и состояние лицензий |

`summary.statuses` всегда содержит четыре статуса каталога, чтобы график не
менял набор колонок. `summary.categories` агрегирует продукты по категории.

Коды рисков: `banned_product`, `license_overuse`, `expired_license`,
`idle_license`, `inactive_product`, `unmatched_installations`.

## Интерфейс

`/sam` — KPI (хосты, продукты, лицензии, комплаенс, риск в рублях,
замороженные деньги), уровень риска, рекомендации, графики по статусам и
категориям, топ рисков с фильтрами по категории и уровню риска, баланс
лицензий с переходом в карточку продукта.

`/sam/compliance` — те же KPI и рекомендации, таблица
«куплено / активно / установлено / дельта / риск / состояние / рекомендация».
Состояния `over`, `under`, `banned`, `expired` выделены цветом и бейджами.
Фильтры по категории, уровню риска и состоянию работают на клиенте по строкам,
которые уже вернул сервер.

Карточка продукта (`/sam/catalog/{id}`) показывает лицензии и хосты, карточка
хоста (`/sam/inventory/{id}`) — установленное ПО и состояние лицензий. Это
даёт переход «риск → продукт → хост → установка».

Каждый экран использует общий `SamPageState`: скелетон загрузки, пустое
состояние, ошибка с повтором и успех. Мобильная вёрстка проверяется на 375px.

Тема сайта переключается кнопкой в шапке: она выставляет
`data-theme="light|dark"` на `<html>` и сохраняет выбор в `localStorage`.
Сохранённый выбор применяется до первого рендера, поэтому переход между
страницами и перезагрузка не мигают чужой палитрой. SAM использует те же
общие токены, что и остальной сайт.
