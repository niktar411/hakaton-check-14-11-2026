# Материалы кейса SAM 2026 (ПАО «Сургутнефтегаз»)

Исходные файлы организаторов хакатона. Текстовое описание кейса и требований —
`docs/cases/sam-2026.md`; архитектура и план блоков — `docs/arch/sam.md`.

| Файл | Что внутри |
| --- | --- |
| `Хакатон_СурГУ_2026_Описание_задачи.docx` | Постановка задачи: цели, роли, критерии оценки, требования к решению |
| `Хакатон_СурГУ_2026_Перечень_ПО.xlsx` | Каталог ПО: вендор, версии, тип лицензии, признаки свободного ПО |
| `Хакатон_СурГУ_2026_Перечень_лицензий.xlsx` | Типы лицензий и их условия (GPL, LGPL, MIT, Apache, проприетарные и т. д.) |
| `Хакатон_СурГУ_2026_Дашборд.xlsx` | Выгрузка инвентаризации: компьютеры, серийные номера, установленное ПО |
| `Хакатон_СурГУ_2026_Презентация.pptx` | Презентация кейса от организаторов |

## Как использовать в коде

Файлы — источник данных для импорта инвентаризации и каталога ПО, а не рантайм-зависимость.
Их не читает приложение: данные переносятся в БД миграциями и сид-скриптами,
чтобы демо работало без Excel.

## Правки

Это архив организаторов. Не редактировать содержимое — при необходимости
добавлять производные файлы рядом с явным суффиксом (например, `*.normalized.csv`).
