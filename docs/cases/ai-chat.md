# Кейс «AI-платформа команды»

Кейс первой половины хакатона: командная AI-платформа с чатом, планером,
админкой и асинхронным coding-агентом. Это рабочая среда, в которой команда
планирует работу и готовит блоки второго кейса — SAM.

## Цель

Показать полный сценарий: пользователь ставит задачу в AI-чате, агент выполняет
блок, второй пользователь получает изменение и подтягивает его.

## Ключевой сценарий

1. Первый участник описывает задачу в чате.
2. Модель уточняет требования (один раунд) и после подтверждения даёт решение.
3. Решение превращается в coding-задачу: агент работает в изолированном
   рабочем дереве, гоняет проверки и открывает MR (никогда не мержит сам).
4. Второй участник получает уведомление о готовом блоке и кнопкой «Подтянуть»
   видит изменения в своём чате.
