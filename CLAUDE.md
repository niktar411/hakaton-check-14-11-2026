<Проект> — <одна фраза о продукте>. SolidJS + TypeScript (Vite, Tailwind v4, CSS Modules)
на клиенте, **Go** (chi + huma, sqlc + pgx, goose, slog) на сервере, PostgreSQL 18,

Правила по типу файла лежат в `.claude/rules/` и подгружаются сами.

## Команды

Менеджер пакетов JS — **только Bun** (npm/yarn/pnpm/npx блокирует хук).

```bash
bun install
bun run lint            # Biome, ошибок должно быть 0 (lint:fix — автопочинка)
bun run slop            # проверка на заглушки и мусор (то же делают хуки и CI)
bun run typecheck       # типы скриптов и хуков
bun run test            # тесты scripts/
bun run new:page <имя> --title "<Заголовок>" [--path /url]
bun run new:component <Имя>
bun run new:route <ресурс>
bun run new:migration <описание_snake_case>
bun run hooks:install   # один раз: включить .githooks/pre-push
```

## Definition of Done

Задача сделана, только если:
1. Функция работает полностью: **ни заглушек, ни моков, ни TODO, ни «потом доделаем»**.
2. Есть все состояния: загрузка (скелетон), пусто, ошибка (toast), успех.
3. Тексты через i18n, вид через токены и `shared/ui`, вёрстка проверена на 375px.
4. Сервер: права проверены, ошибки обёрнуты, `gen:api` выполнен, есть тест.
5. Требование неясно — выбери вариант по шаблону и **в конце ответа перечисли допущения**.
   Не сделал часть — **скажи прямо**, не маскируй заглушкой.

## Сквозные правила

- **Новое — через генератор** (`bun run new:*`), а не с чистого листа. Генератор кладёт
  правильный скелет, ты дописываешь логику.
- **Контракт API — только Go-типы** → `bun run gen:api`. Сгенерированное
  (`api/openapi.json`, `client/src/shared/api/schema.d.ts`, `server/internal/db/sqlc/`)
  руками не правим — хук не даст.
- **Цвета, радиусы, шрифт, размеры текста — только токены** (`client/src/shared/styles/tokens.css`).
  Стандартной палитры Tailwind нет: `bg-red-500` не существует. Произвольные значения
  (`bg-[#f00]`, `w-[347px]`) и склеенные классы (`bg-${color}`) ловит Biome; если правда
  нужно — `// biome-ignore lint/nursery/noTailwindArbitraryValue: <причина>` строкой выше.
- **Шрифт один, курсива нет. Браузерных контролов нет:** Select/Checkbox/Dialog/Toast — из `shared/ui`.
- Строки UI — `m.key()`, русских литералов в JSX нет.
- Компонент уже есть в `shared/ui` → расширь его, не создавай `Button2`/`CustomSelect`.
- **Файлы ≤ 1000 строк** (хук блокирует). Сгенерированное и словари — исключение.
- Go: `ctx` первым аргументом в каждом I/O; ошибки — `fmt.Errorf("…: %w", err)`;
  логи — `slog.InfoContext(ctx, "msg", "key", v)`; никаких `fmt.Println`/`log.Print`.
- Цена, права, роль — только с сервера, никогда из тела запроса.
- Новая публичная страница → пререндер или SSI + sitemap + robots + `llms.txt` + regex nginx (оба конфига).
- Подавление линтера — только построчно и с причиной:
  `// biome-ignore lint/<группа>/<правило>: <причина>`, `//nolint:<линтер> // <причина>`.
- Изменил поведение подсистемы — обнови её файл в `docs/arch/`, а не этот.

## Защита (что сработает само)

Хуки в `.claude/hooks/`: guard (миграции, npm, сгенерированные файлы, force-push),
slop-guard (заглушки и мусор — до записи на диск), file-size (1000 строк),
lint (Biome / gofmt после правки), gen-reminder (перегенерировать API/sqlc),
prompt-router (подсказывает навык под промт), done-gate и typecheck (дают до трёх попыток исправления; затем останавливают
работу с явным сообщением «проверка не пройдена» для человека). Правила slop-check одни для хуков, pre-push и CI — `scripts/slop-check.ts`.

Субагенты — для длинного вывода: **test-runner** (проверки), **reviewer** (инварианты
перед push), **translator** (словари), **ui-auditor** (вёрстка в браузере на 375/768/1280).
